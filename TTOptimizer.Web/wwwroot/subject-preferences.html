Subject preferences

Configure scheduling preferences for this subject. Default values are inherited from the organization.

Scheduling preferences

These rules are evaluated separately for each class using this subject.

Weekly distribution

Control how often and on how many days a subject appears.

Spread across days

Prefer using as many distinct teaching days as the weekly lesson count reasonably allows.

Max occurrences per day

Limit how many lessons of this subject a class should have in one day.

Lesson blocks

Choose whether consecutive same-subject lessons are desirable.

Prefer double lessons

Prefer pairing lessons into consecutive blocks. An unavoidable single lesson for an odd weekly count is not penalized.

Avoid double lessons

Discourage adjacent lessons of this subject for the same class.

Prefer double lessons and Avoid double lessons cannot both be enabled.
