About ClassFlow

A school timetable management and optimization application built with ASP.NET Core, C++, Entity Framework Core and JavaScript.

Project overview

ClassFlow is a web application for preparing school timetable data, running timetable optimization and presenting the generated schedule in a clear and filterable form.

The project combines a browser-based user interface, an ASP.NET Core backend, a PostgreSQL database and an external C++ optimization engine. Each layer has a separate responsibility, which keeps the application easier to develop, test and extend.

What ClassFlow does

Users can manage the main resources required to build a timetable: teachers, classes, subjects, rooms and lesson requirements.

ClassFlow also supports resource availability, scheduling rules, optimization settings, preprocessing validation and live optimization progress. When optimization completes, the generated timetable is shown in a table that can be filtered by class, teacher and room.

JSON is used as the data contract between the ASP.NET Core backend and the C++ engine. SignalR is used to send optimization progress updates from the server to the browser.

Technologies used

ASP.NET Core

Web API, controllers, services, dependency injection, external process execution and application orchestration.

C++

External optimization engine responsible for generating and evaluating timetable candidates.

PostgreSQL

Relational database used to store organizations, users, teachers, classes, rooms, subjects, requirements and scheduling data.

Entity Framework Core

Database access, domain models, migrations and PostgreSQL integration through the Npgsql provider.

SignalR

Live optimization progress updates sent from the server to the dashboard.

JavaScript

API communication, forms, navigation, table rendering, filtering, CSV export and browser storage.

HTML / CSS

Responsive application layout, resource pages, forms, tables and the Classic Ink visual theme.

Implemented features

  • Demo login with prepared school datasets.
  • Management of teachers, classes, rooms, subjects and lesson requirements.
  • Weekly availability configuration for teachers, classes and rooms.
  • Scheduling rules and constraints.
  • Configurable genetic algorithm parameters and penalty values.
  • ASP.NET Core integration with an external C++ optimization engine.
  • Live optimization progress using SignalR.
  • Validation and user-friendly preprocessing messages.
  • Filterable timetable result by class, teacher and room.
  • CSV export and storage of the latest result in the browser.

Project goals

ClassFlow is both a practical application and a learning project. It is used to develop experience in modern C++, ASP.NET Core, PostgreSQL, database design, frontend development, process integration, real-time communication and deployment.

A major design goal is to keep the optimization engine independent from the web interface. The C++ engine focuses on optimization, the backend prepares and validates data, and the browser presents the result in a form useful to the user.

Current status

ClassFlow is a working prototype under active development. Resource management, availability, optimization settings, timetable generation, progress reporting, filtering and CSV export are already available.

The current development work focuses on improving diagnostics and making execution of the external optimization engine reliable in the server environment.
